# نقشه راه فازها

فاز جاری (**Foundation**) تنها زیرساخت را می‌سازد: سیستم ماژول، ماژول `Core`، نصاب گرافیکی، فرانت‌اند
RTL، Seeder‌ها، مستندات و تست‌های پایه. منطق کسب‌وکار ماژول‌های دامنه **آگاهانه به فازهای بعد موکول شده**
و در حال حاضر هر ماژول فقط ساختار پوشه، ServiceProvider، config و فایل route دارد.

## فاز ۱ — Foundation (انجام‌شده در این PR)

- اسکلت Laravel 12 (PHP 8.2+، MySQL 8+) با ساختار بندهای ۱۳۷ و ۲۰۱
- سیستم ماژول بر پایه ServiceProvider + `ModuleServiceProvider` مرکزی + `config/modules.php`
- ماژول `Core`: احراز هویت (username/mobile، Remember Me، Forgot/Reset Password، Logout، Login History)،
  RBAC کامل با چند نقش و Permission‌های granular، Policy‌ها، ساختار سازمانی، `settings`, `audit_logs`,
  `notifications`
- نصاب گرافیکی ۹ مرحله‌ای + `installed.lock` + میان‌افزار هدایت به نصاب + دستور `nursing:install`
- Layout داشبورد (Sidebar/Topbar/User Menu/Breadcrumb/Light-Dark) با برندینگ از `settings`
- Seeder نقش‌ها، Permission‌ها، تنظیمات، ادمین پیش‌فرض و داده نمونه
- مستندات (`docs/`) و تست‌های Feature برای Authentication، Permission، Installer و سیستم ماژول

## بندهای Specification که در این فاز پیاده نشده‌اند

- منطق دامنه و جداول همه ماژول‌های فاز ۲ تا ۶ (نقشه جداول در `docs/database-map.md`)
- گزارش‌سازی و داشبوردهای تحلیلی، خروجی Excel/PDF و چاپ فرم‌ها
- API عمومی/توکن، Webhook و یکپارچه‌سازی با سامانه‌های بیرونی (بیمه، بانک، پیامک، نقشه)
- اپلیکیشن/نمای موبایل و ردیابی موقعیت لحظه‌ای
- صف و Job‌های سنگین، Notification چندکاناله (SMS/Email/Push) با قالب‌های قابل ویرایش
- احراز هویت دو مرحله‌ای، سیاست‌های پیشرفته رمز عبور و مدیریت نشست‌های فعال
- چندزبانگی کامل (در این فاز رابط فارسی/RTL پیاده شده است)
- پشتیبان‌گیری/بازیابی خودکار، پایش سلامت سامانه و صفحه مدیریت به‌روزرسانی
- CI/CD، Docker و استقرار خودکار
- تست‌های جامع واحد/یکپارچه برای ماژول‌های دامنه (در این فاز فقط تست‌های پایه Core)
